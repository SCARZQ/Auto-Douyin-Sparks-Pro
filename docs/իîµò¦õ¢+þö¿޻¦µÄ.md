# 第一部分 · 部署

## 1. 环境要求

| 项目 | 要求 |
|---|---|
| 系统 | Debian 11+ / Ubuntu 20.04+（其他 Linux 也可，需自行装依赖） |
| Python | 3.10 或更高 |
| 内存 | **建议 2GB 以上**（1GB 需要靠 swap，会比较慢） |
| 磁盘 | 至少 3GB（Chromium 本体约 400MB） |
| 网络 | 能访问抖音；服务器在国内体验更好 |

> ⚠️ **为什么吃内存**：续火花靠 Playwright 驱动真实 Chromium 浏览器，
> 浏览器本身就占 300~500MB。1G 内存的机器会频繁 OOM。

---

## 2. 服务器一键部署（推荐）

### 准备

在服务器上拿到项目，二选一：

```bash
# 方式 A：Git 克隆（如果你已上传到自己的仓库）
git clone https://github.com/<你的用户名>/Auto-Douyin-Sparks-Pro.git
cd Auto-Douyin-Sparks-Pro

# 方式 B：上传压缩包
# 用 scp / 宝塔面板 / FinalShell 等把项目目录传上去
```

### 执行部署

```bash
sudo bash deploy/deploy.sh
```

脚本会依次完成：

1. 安装 `python3`、`python3-venv`、`python3-pip`
2. 创建虚拟环境 `.venv/`
3. 安装 `requirements.txt` 里的 Python 依赖
4. 下载安装 Chromium（首次约数百 MB，**耐心等待**）
5. 配置 2GB swap（内存不足时兜底）
6. 设置时区为 `Asia/Shanghai`（**很重要**，否则定时会差 8 小时）
7. 生成访问令牌写入 `.env`
8. 安装并启动 systemd 服务 `auto-douyin-sparks-pro`

### 完成后

脚本结尾会打印：

```
网页地址: http://<服务器IP>:8000
访问令牌: xxxxxxxx
```

浏览器打开这个地址即可。

### 常用命令

```bash
# 查看运行状态
sudo systemctl status auto-douyin-sparks-pro

# 查看实时日志
sudo journalctl -u auto-douyin-sparks-pro -f

# 重启（改完代码/配置后）
sudo systemctl restart auto-douyin-sparks-pro

# 停止
sudo systemctl stop auto-douyin-sparks-pro

# 开机自启（部署脚本已自动设置）
sudo systemctl enable auto-douyin-sparks-pro
```

## 3. 手动部署

不想用脚本，或环境不是 Debian 系：

```bash
# 1) 进入项目目录
cd Auto-Douyin-Sparks-Pro

# 2) 建虚拟环境
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate

# 3) 装依赖
pip install --upgrade pip
pip install -r requirements.txt

# 4) 装浏览器
playwright install --with-deps chromium

# 5) 设置时区（关键）
sudo timedatectl set-timezone Asia/Shanghai

# 6) 启动
python app.py
```

默认监听 `8000` 端口，可用环境变量改：

```bash
PORT=9000 python app.py
```

### 配成 systemd 服务

把 `deploy/auto-douyin-sparks-pro.service` 里的 `__DIR__` 和 `__VENV__`
替换成实际路径，然后：

```bash
sudo cp deploy/auto-douyin-sparks-pro.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now auto-douyin-sparks-pro
```

## 4. Windows 本机运行

如果你只是自己用，跑在 Windows 上完全没问题（**不用买服务器**）：

```powershell
# 1) 装 Python 3.10+（勾选 Add to PATH）
# 2) 在项目目录执行
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium

# 3) 启动
python app.py
```

浏览器打开 `http://127.0.0.1:8000`。

> 本机跑的好处：登录态在自己电脑上获取，**风控概率更低**。
> 缺点是电脑关机就不发了 —— 可以设置 Windows 任务计划程序开机自启。

## 5. 配置外网访问（可选）

默认只有内网能访问。想在外面也能用：

### 方式 A：Cloudflare Tunnel（免费，推荐）

```bash
# 安装 cloudflared 后
cloudflared tunnel --url http://localhost:8000
```

会给你一个 `https://xxx.trycloudflare.com` 临时地址。
系统已适配 Cloudflare，访问 IP 记录能正确识别真实 IP。

### 方式 B：frp 内网穿透

需要一台有公网 IP 的服务器做中转，配置略复杂。

### 方式 C：直接开防火墙端口

```bash
sudo ufw allow 8000
```

> ⚠️ 裸奔在公网**至少要做三件事**：
> 1. 改掉默认密码 `admin/admin`
> 2. 不要把地址发到公开群
> 3. 最好套一层 Nginx + HTTPS

## 6. 升级到新版本

```bash
cd Auto-Douyin-Sparks-Pro

# 1) 备份数据（重要！里面有登录态和用户）
cp -r data data.backup.$(date +%F)

# 2) 更新代码
git pull          # 或重新上传覆盖

# 3) 更新依赖（如果 requirements.txt 有变化）
.venv/bin/pip install -r requirements.txt

# 4) 重启
sudo systemctl restart auto-douyin-sparks-pro
```

> **`data/` 目录不会被覆盖**，你的账号、好友配置、登录态都会保留。
>
> 如果前端页面没变化，浏览器按 **Ctrl + F5** 强制刷新一次。

# 第二部分 · 使用

## 1. 首次登录

打开网页，用默认管理员账号登录：

```
账号：admin
密码：admin
```

> 🔒 **登录后第一件事：改密码。**
> 右上角账号菜单 → 个人中心 → 修改密码。

---

## 2. 四步跑通

### 第 1 步 · 登录抖音

底部 **「凭证」** 页面，二选一：

- **网页登录**：点「网页登录」，用手机抖音 App 扫码
- **登录态登录**：上传本机导出的 `state.json`

看到 **绿色「已登录」** 就成功了。

### 第 2 步 · 获取并勾选好友

1. 底部 **「好友」** 页面
2. 点 **「获取聊天列表」**，等 10~60 秒
3. 用搜索框找到要续火花的好友，**勾选**
4. 点 **「保存勾选与消息」**

> 好友 **只能从列表勾选**，不能手动输名字。

### 第 3 步 · 设置发送时间

底部 **「定时」** 页面：

| 字段 | 建议值 | 说明 |
|---|---|---|
| 发送时间 | `09:30` | 每天几点开始跑 |
| 抖动窗口 | `5~15` 分钟 | 在设定时间后随机延后 0~N 分钟 |
| 好友间隔（最小） | `3` 秒 | 两个好友之间最少等多久 |
| 好友间隔（最大） | `8` 秒 | 最多等多久，系统在这区间随机 |
| 每次最多发送 | `0` | 0 = 不限 |

填完点保存。

### 第 4 步 · 验证

回 **「概览」**：

- 先点 **「干跑测试」** —— 只模拟不真发，确认流程通
- 确认没问题再点 **「立即发送」** 或等定时自动执行

之后每天会自动运行，你可以不管了。

## 3. 各页面说明

| 页面 | 作用 |
|---|---|
| **概览** | 看登录状态、是否占用、上次/下次发送时间、授权到期日；手动发送 / 干跑 / 停止；**使用卡密续期** |
| **凭证** | 管理抖音登录态。显示未登录时来这里重新登录 |
| **好友** | 读取聊天列表、勾选好友、设置消息模板、配置 AI 文案 |
| **定时** | 发送时间、抖动窗口、好友间隔、单次上限 |
| **日志** | 每次运行的详细记录，按天保存，可发到邮箱 |
| **我的** | 账号信息、改用户名/密码/邮箱、使用帮助、退出登录 |

## 4. AI 文案配置（可选）

在 **「好友」** 页面找到「AI 续火花文案」区域：

1. 打开 **「启用 AI 文案」**
2. 填 **API 地址** —— 到 `/v1` 为止，**不要**带 `/chat/completions`
   - 官方：`https://api.openai.com/v1`
   - 中转：`https://你的域名/v1`
3. 填 **API Key**（`sk-` 开头）
4. 填 **模型**（如 `gpt-4o-mini`）
5. 写 **系统提示词**
6. 先点 **「测试 API 连通」**，再点 **「测试提示词」** 预览
7. 保存

> **兜底机制**：AI 调用失败会自动回退到你的**消息模板**，不会发不出去。

## 5. 授权与卡密

两种模式：

- **独立模式**：无到期限制，一直可用
- **授权模式**：有到期时间，到期自动停用

### 续期

「概览 → 使用卡密」输入卡密 → 点兑换。天数**叠加**到现有到期时间。

### 卡密面额

开头数字就是天数：

| 前缀 | 面额 | 前缀 | 面额 |
|---|---|---|---|
| `1...` | 1 天 | `30...` | 1 个月 |
| `3...` | 3 天 | `90...` | 3 个月 |
| `7...` | 7 天 | `180...` | 6 个月 |
| `15...` | 15 天 | `365...` | 1 年 |

# 第三部分 · 常见问题

## 部署类

**Q：`deploy.sh` 跑一半失败了怎么办？**

脚本可重复执行。重新跑 `sudo bash deploy/deploy.sh` 即可，
已完成的步骤会自动跳过。

**Q：Chromium 下载太慢 / 卡住？**

```bash
# 换国内镜像
export PLAYWRIGHT_DOWNLOAD_HOST=https://npmmirror.com/mirrors/playwright
.venv/bin/playwright install chromium
```

**Q：1G 内存的服务器跑不起来？**

确认 swap 生效：

```bash
swapon --show
free -h
```

没有的话手动加：

```bash
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile && sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
```

更根本的办法是升级到 2G 内存。

**Q：`systemctl status` 显示 failed？**

```bash
# 看具体错误
sudo journalctl -u auto-douyin-sparks-pro -n 100 --no-pager
```

常见原因：
- 端口 8000 被占用 → `PORT=9000` 换端口
- 依赖没装全 → 重跑 `pip install -r requirements.txt`
- Chromium 没装 → `.venv/bin/playwright install chromium`

**Q：浏览器打开是白屏？**

1. **Ctrl + F5** 强制刷新（前端资源有缓存）
2. 按 F12 看 Console 报什么错
3. 确认 `static/dist/app.min.js` 文件存在

**Q：能跑在 Docker 里吗？**

可以，但官方**没有提供 Dockerfile**。需要自己写，注意：
- 基础镜像要有 Chromium 依赖
- 容器内存限制至少给 2G
- 需要挂载 `data/` 持久化

---

## 登录与授权类

**Q：提示「未登录」或「登录态已失效」？**

抖音登录态过期了。去 **「凭证」** 重新扫码或重新上传 `state.json`。

**Q：显示「当前账号尚未登录抖音，无法进行任务」？**

同上，先去「凭证」完成登录。登录成功后提示会自动消失。

**Q：忘了管理员密码？**

```bash
# 停服务
sudo systemctl stop auto-douyin-sparks-pro

# 删掉用户文件（会重建默认 admin/admin）
mv data/users.json data/users.json.bak
mv data/sessions.json data/sessions.json.bak 2>/dev/null

# 重启
sudo systemctl start auto-douyin-sparks-pro
```

> ⚠️ 这会**丢失所有普通用户账号**，但抖音账号配置（`data/accounts/`）还在。

**Q：卡密兑换提示无效？**

1. 检查是否输错（卡密 24 位，格式 `XXXX-XXXX-XXXX-XXXX-XXXX-XXXX`）
2. 检查是否已被使用过
3. 老版本 16 位卡密**仍可兑换**，不受影响

**Q：授权到期了数据会丢吗？**

不会。到期只是停止发送，账号配置、好友列表、日志都保留。
续期后立刻恢复。

## 发送类

**Q：显示验证码 / 操作频繁？**

系统检测到风控会**自动停止本轮**，这是保护机制。
**次日再试，不要频繁重试** —— 反复重试只会加重风控。

**Q：发送时间不准 / 延迟了？**

正常现象，两个原因：
1. **抖动窗口**设计：在设定时间后随机延后 0~N 分钟
2. 网络与平台因素，可能再晚几分钟到几十分钟

只要日志里有成功记录，就说明任务正常执行了。

**Q：想立刻测一次，又不想真发消息？**

「概览」→ **「干跑测试」**，只走流程不实际发送。

**Q：好友列表是空的 / 读取失败？**

1. 点「获取聊天列表」重新读
2. 一直失败就检查「凭证」页是不是绿色「已登录」

**Q：多个抖音账号会互相影响吗？**

不会。每个账号有独立的登录态、好友配置、日志
（`data/accounts/<账号>/`）。但**同时运行多个浏览器很吃内存**，
建议 2G 内存最多跑 2 个账号。

**Q：能加多少好友？**

技术上不限，但**强烈建议 10 人以内**。这个项目定位是个人自用，
大批量会显著提高风控概率。

**Q：为什么 V8 比 V1 先执行？**

等级数字**越大越优先**（V8 最高）。这是设计如此：
管理员给重要账号设置高等级，让它们优先跑。

## 邮件类

**Q：收不到邮件通知？**

检查两处：
1. **「我的 → 收件邮箱」** 是否填了
2. **「管理后台 → 邮箱设置」** 是否配好 SMTP 并且测试通过

两个都满足才会发信。

**Q：SMTP 测试失败？**

| 邮箱 | 常见配置 |
|---|---|
| QQ 邮箱 | `smtp.qq.com` 端口 `465`（SSL）；密码填**授权码**不是登录密码 |
| 163 邮箱 | `smtp.163.com` 端口 `465`；同样需要授权码 |
| Gmail | `smtp.gmail.com` 端口 `587`（STARTTLS）；需要应用专用密码 |

最常见的原因是**用了登录密码而不是授权码**。

## 运维类

**Q：怎么看运行日志？**

```bash
# 服务日志
sudo journalctl -u auto-douyin-sparks-pro -f

# 业务日志（按账号按天）
ls data/accounts/<账号>/logs/
tail -f data/accounts/<账号>/logs/$(date +%F).log
```

网页端「日志」页面也能看，还能发到邮箱。

**Q：data 目录要备份吗？**

**必须备份**，里面是全部数据：

```bash
tar -czf backup-$(date +%F).tar.gz data/
```

特别是 `data/accounts/*/state.json`（抖音登录态），
丢了就要重新扫码登录。

**Q：怎么迁移到新服务器？**

1. 老服务器：`tar -czf backup.tar.gz data/`
2. 新服务器：装好项目、跑完 `deploy.sh`
3. 把 `backup.tar.gz` 解压覆盖到新服务器的 `data/`
4. 重启服务

**Q：改了前端代码怎么生效？**

前端是压缩混淆过的，需要重新构建：

```bash
cd docs
node build.js
python gzip_assets.py
sudo systemctl restart auto-douyin-sparks-pro
```

详见 `docs/前端构建说明.md`。

**Q：怎么关闭前端调试保护？**

排障时可临时开放未混淆版本：

```bash
EXPOSE_DEBUG_JS=1 sudo systemctl restart auto-douyin-sparks-pro
# 然后访问 http://你的地址/?debug=1
```

**排障完记得关掉**，否则源码可被下载。

**Q：服务器时间不对，定时差了几小时？**

```bash
sudo timedatectl set-timezone Asia/Shanghai
sudo systemctl restart auto-douyin-sparks-pro
```

**Q：`ACCESS_LOG` 是什么？**

默认关闭（省磁盘 IO）。想排查请求问题：

```bash
ACCESS_LOG=1 sudo systemctl restart auto-douyin-sparks-pro
```

## data 目录（重要）

```
data/
├── users.json            用户账号与密码
├── sessions.json         登录会话
├── licenses.json         授权天数（独立存放，防误删）
├── card_keys.json        卡密
├── invite_keys.json      注册密钥
├── email_config.json     SMTP 配置（含密码）
├── site_settings.json    站点设置
├── visit_ips.json        访问 IP 记录
└── accounts/             各抖音账号数据
    └── <账号名>/
        ├── state.json    ⚠️ 抖音登录态（等同账号密码）
        ├── config.json   定时与好友配置
        ├── runtime.json  运行状态
        └── logs/         按天日志
```

> ⚠️ **`state.json` 泄露等于账号被顶。**
> 千万不要把 `data/` 上传到任何公开仓库或网盘。

## 环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | `8000` | 服务端口 |
| `AUTH_TOKEN` | 空 | 旧版兼容令牌，**建议不设** |
| `ACCESS_LOG` | `0` | 设 `1` 打开访问日志 |
| `EXPOSE_DEBUG_JS` | `0` | 设 `1` 允许下载未混淆前端（仅排障） |
