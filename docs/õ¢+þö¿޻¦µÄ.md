# 云逸续火花助手 · 使用说明

> 本系统会自动向指定好友发送消息，帮你维持聊天火花不中断。
> 首次使用请按「快速上手」4 步操作，约 3 分钟即可完成。

---

## 一、快速上手（4 步）

### 第 1 步 · 登录抖音

打开底部 **「凭证」** 页面，二选一：

- **网页登录**：点「网页登录」，在弹出的浏览器窗口用手机抖音 App 扫码
- **登录态登录**：点「上传抖音登录态」，选择本机导出的 `state.json` 文件

看到顶部显示 **绿色「已登录」** 就成功了。
如果显示「未登录」，说明登录态失效，重新登录一次即可。

### 第 2 步 · 获取并勾选好友

1. 打开底部 **「好友」** 页面
2. 点 **「获取聊天列表」**，等待读取（约 10～60 秒）
3. 在列表里 **勾选需要续火花的好友**
4. 点 **「保存勾选与消息」**

> ⚠️ 好友 **只能从列表勾选**，不能手动输入名字。

### 第 3 步 · 设置发送时间

打开底部 **「定时」** 页面：

| 项目 | 建议值 | 说明 |
|---|---|---|
| 每天发送时间 | 例如 09:30 | 每天自动开跑的时间 |
| 时间抖动窗口 | 5～15 分钟 | 在设定时间后 0～N 分钟内随机开始，更像真人 |
| 好友间隔 | 3～8 秒 | 每发一位好友间隔多久 |
| 每次最多发送人数 | 0（不限） | 0 表示不限制 |

设置完点 **「保存定时设置」**。

### 第 4 步 · 查看运行结果

- **「概览」**：看登录状态、是否占用、上次/下次发送时间、授权到期日
- **「日志」**：看每次发送的详细记录（成功谁、失败谁、原因）

## 二、各页面说明

### 概览

- 顶部显示当前抖音 **头像 / 昵称 / 抖音号**
- **是否占用续火花**：运行中 / 空闲可用 / 无法进行任务
- **上一次发送时间**、**下一次发送时间**
- **授权天数 / 到期日期**：独立模式显示「无限制」
- **「使用卡密」**：输入卡密即可自助续期
- 底部按钮：**立即发送**（手动跑一次）、**干跑测试**（只模拟不真发）、**强制停止**

### 凭证

管理抖音登录状态。登录态过期时来这里重新登录。

### 好友（好友与消息）

- 读取抖音聊天列表、勾选续火花好友
- 设置 **消息模板**（每行一条，每次随机选一条）
- 配置 **AI 续火花文案**（可选）

### 定时

设置每天发送时间、抖动窗口、好友间隔、单次上限。

> 💡 因网络或不可抗因素，实际发送时间可能略有延迟，属正常现象。

### 日志

查看运行明细，按天保存。支持「自动刷新」和「发送今日日志到邮箱」。

### 我的（个人中心）

- 查看 **登录账号 / 账号等级 / 注册时间**
- **修改账号用户名**、**修改密码**、**收件邮箱**
- 联系客服、使用帮助
- 退出登录

## 三、AI 文案怎么用（可选）

在 **「好友」** 页找到「AI 续火花文案」区域：

1. 打开 **「启用 AI 文案」** 开关
2. 填写 **API 地址**（填到 `/v1` 为止，**不要**带 `/chat/completions`）
   - 官方示例：`https://api.openai.com/v1`
   - 中转示例：`https://你的域名/v1`
3. 填写 **API Key**（`sk-` 开头）
4. 填写 **模型**（如 `gpt-4o-mini`）
5. 写 **系统提示词**（告诉 AI 怎么写）
6. 先点 **「测试 API 连通」**，再点 **「测试提示词」** 预览效果
7. 确认没问题后点 **「保存勾选与消息」**

> 如果 AI 调用失败，系统会自动回退到你的**消息模板**，不会发不出去。

## 四、授权与续期

系统有两种模式：

- **独立模式**：无到期限制，一直可用
- **授权模式**：有到期时间，到期后自动停用

**怎么续期？**
拿到卡密后，在 **「概览 → 使用卡密」** 输入卡密，点「立即兑换」，
天数会自动叠加到现有到期时间上。

**卡密面额怎么看？**
卡密开头数字就是天数：

| 前缀 | 面额 |
|---|---|
| `1...` | 1 天 |
| `3...` | 3 天 |
| `7...` | 7 天 |
| `15...` | 15 天 |
| `30...` | 1 个月 |
| `90...` | 3 个月 |
| `180...` | 6 个月 |
| `365...` | 1 年 |

## 五、常见问题

**Q：提示「未登录」或「登录态已失效」？**
A：登录态过期了。到 **「凭证」** 页面重新扫码登录，或重新上传 `state.json`。

**Q：显示「当前账号尚未登录抖音，无法进行任务」？**
A：同上，先去 **「凭证」** 完成抖音登录。

**Q：任务没发出去 / 显示验证码、操作频繁？**
A：系统检测到风控会自动停止本轮，这是**保护机制**。
请 **次日再试，不要频繁重试**，否则可能加重风控。

**Q：消息发送时间不准 / 延迟了？**
A：正常现象。发送时间有**随机抖动**设计，加上网络因素，
实际时间可能比设定值晚几分钟到几十分钟。

**Q：好友列表是空的？**
A：点「获取聊天列表」重新读取；如果失败，检查抖音登录态是否有效。

**Q：收不到邮件通知？**
A：检查两点：①「我的 → 收件邮箱」是否填写；
② 管理员是否已配置发件邮箱（SMTP）。

**Q：怎么修改登录账号名？**
A：到 **「我的 → 修改账号用户名」**。
注意：改名后你的**账号目录会同步改名**，不影响任何数据。

**Q：能加多少个好友？**
A：建议 **少量好友（10 人以内）**，间隔不要太短。
本系统定位是个人自用，不建议大批量使用。

## 六、使用建议（重要）

1. **仅限本人账号、少量好友自用**，请勿用于营销或对外服务
2. 好友数量控制在少量，发送间隔不要太短
3. 登录态尽量在**常用网络环境**获取，减少异地风控
4. 出现验证码 / 操作频繁时**停止本轮，次日再试**
5. 不要把 `data/` 目录或登录态文件分享给任何人
