快速上手

按顺序做完这 4 步，就可以撒手不管了

1

登录抖音 必做

打开底部 「凭证」 页面，二选一：

  • 网页登录：点「网页登录」，在弹出的浏览器窗口用手机抖音 App 扫码
  • 登录态登录：点「上传抖音登录态」，选择本机导出的 state.json
看到顶部显示 绿色「已登录」 就成功了。如果显示「未登录」，说明登录态失效，重新登录一次即可。
2

获取并勾选好友 必做

  • 打开底部 「好友」 页面
  • 点 「获取聊天列表」，等待读取（约 10～60 秒）
  • 在列表里 勾选需要续火花的好友
  • 点 「保存勾选与消息」
好友 只能从列表勾选，不能手动输入名字。
3

设置发送时间 必做

打开底部 「定时」 页面，按下表填写后点「保存定时设置」：

项目建议值说明
每天发送时间09:30每天自动开跑的时间
时间抖动窗口5～15 分钟在设定时间后 0～N 分钟内随机开始，更像真人
好友间隔3～8 秒每发一位好友间隔多久
每次最多发送人数00 表示不限制
4

查看运行结果

  • 「概览」：看登录状态、是否占用、上次/下次发送时间、授权到期日
  • 「日志」：看每次发送的详细记录（成功谁、失败谁、原因）
想立刻试一次效果，可以在「概览」点 「干跑测试」（只模拟不真发）。

AI 文案怎么用

可选功能 · 让每句话都不一样

AI

在 「好友」 页找到「AI 续火花文案」区域，按下面顺序配置：

  • 打开 「启用 AI 文案」 开关
  • 填 API 地址 —— 填到 /v1 为止，不要带 /chat/completions
    官方：https://api.openai.com/v1 ｜ 中转：https://你的域名/v1
  • 填 API Key（sk- 开头）
  • 填 模型（如 gpt-4o-mini）
  • 写 系统提示词（告诉 AI 怎么写）
  • 先点 「测试 API 连通」，再点 「测试提示词」 预览效果
  • 确认没问题后点 「保存勾选与消息」
如果 AI 调用失败，系统会自动回退到你的 消息模板，不会发不出去。

授权与续期

两种模式 · 以及卡密怎么用

独立模式

无到期限制，一直可用。没有「到期」概念，不用管续期。

授权模式

有到期时间，到期后自动停用。需要用卡密续期。

怎么用卡密续期

拿到卡密后，在 「概览 → 使用卡密」 输入卡密，点「立即兑换」。 天数会 自动叠加 到现有到期时间上，不会覆盖。
